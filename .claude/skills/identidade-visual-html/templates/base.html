Identificamos a Trava

Com base nos dados do funil e do comparativo ano a ano, esta é a restrição que mais limita o faturamento do trimestre.

Restrição principal

Fechamento
Orçamento → Venda Ganha

Quem chega até a proposta não está fechando. A conversão caiu de 56,10% (abril) para 13,33% (junho), enquanto vendas perdidas subiram de 43,90% para 86,67% dos orçamentos.
